Additional native testing uncovered a same-application routing issue: an event naming window A could still reach the application's key window B. The helper now verifies the selected keyboard window, uses a reported foreground selection when background selection fails, and refuses input if selection cannot be established. AX text insertion also verifies its owning window and skips web accessibility mirrors before writing.

The UI keeps Stop available for the complete lease, including thinking gaps and while another task is selected, and routes it to the owning task. Activity identifies the target application and actual delivery mode; unconfirmed delivery is surfaced consistently. The status badge is extracted from the main pane to keep its branching manageable.

## Remaining release qualification

Test an installed Developer ID-signed build through update, TCC denial/revocation/regrant, and helper replacement. Exercise macOS 14 and current macOS, real mixed-scale display hot-plugging, multiple Spaces, browser selects/file panels, and end-to-end tasks with multiple actual vision models. Existing adapter tests and synthetic geometry tests cannot substitute for that hardware/provider matrix.

The original audit separately identified product parity decisions: Codex-style remembered per-application grants with revocation, and opt-in operation on a locked Mac. This change preserves Synara's thread/provider authority model and refuses locked input; it does not introduce those additional product features.
