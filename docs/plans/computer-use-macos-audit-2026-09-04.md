# macOS computer-use audit — what actually needs improving

Branch `claude/computer-use-macos-s1vpp0`, audited at snapshot `67d1fa05a` (2026-09-04).

Six read-only audits (Swift helper, server backend, tool surface + policy, web/desktop UX,
packaging/signing, maintainability/docs) fed this list. Every item marked **verified** was
re-checked against the code by the orchestrator, not just reported by an auditor; items
marked _plausible_ were proven by reading but not executed (they would have required driving
the user's desktop). Findings that were pure noise are omitted or collapsed into one line.

Bar: "as good as the official Codex app's computer use, with any model." Hard constraints: the
real cursor never moves; the helper never takes or reorders focus outside the explicit
foreground rung; results are truthful.

Note on the comparison target: the OSS `openai/codex` repo has no discrete computer-use tool —
the Codex app's computer use is a code-execution REPL (`cua_repl`). The comparable published
surfaces are OpenAI's `computer_use_preview` and Anthropic's `computer_2025xxxx` tools; that is
what the tool-surface findings measure against.
